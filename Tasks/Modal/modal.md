1. Open Modal
	•	A button like “Open Modal”
	•	Clicking it should:
	•	Show modal
	•	Add overlay (background dim)

⸻

2. Close Modal

User should be able to close modal in 3 ways:
	•	Click ❌ close button
	•	Click outside modal (overlay)
	•	Press ESC key

⸻

3. Structure

Modal should contain:
	•	Title
	•	Description/content
	•	Close button
	•	Optional: action buttons (Save / Cancel)

⸻

4. Center Positioning
	•	Modal should be centered (both vertically + horizontally)

⸻

5. Overlay
	•	Dark background behind modal
	•	Slight transparency (e.g., rgba)

⸻

⚙️ Intermediate Requirements (Very Important)

6. Prevent Background Scroll
	•	When modal is open → page should NOT scroll

⸻

7. Focus Handling (basic)
	•	When modal opens → focus inside modal
	•	(Bonus: focus first button/input)

⸻

8. Smooth Animation
	•	Fade in / scale effect when opening
	•	Fade out when closing

⸻

🔥 Advanced (Bonus Points in Interview)

9. Focus Trap
	•	Tab key should stay inside modal (not go outside)
